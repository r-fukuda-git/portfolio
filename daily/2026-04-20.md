# クエリパラメータ
一覧取得のAPIやハンドラーを実装する際、クエリパラメータからの入力をそのまま信じず、型変換時のエラーハンドリングや不正な値（負の数など）へのフェイルセーフ（デフォルト値のフォールバック）を実装し、堅牢なページネーションを設計

# := と = の決定的な違い
:= (新規作成): 「まだ箱がないから、新しく箱を作って中身を入れてね」という指示（ショート変数宣言と呼びます）。
= (上書き): 「すでに手元にある既存の箱の中身を捨てて、新しいものを入れ直してね」という指示（単なる代入です）。

# 無名構造体（Anonymous Struct）
- 普通は type 構造体名 struct と名前をつけて設計図
- 「設計図を作ること」と「その設計図通りに箱を作って中身を入れること」を、同時に1発でやっている書き方
- 普通のパターンは何度も同じ形の箱を作るため設計する必要があるけど、今回無名は一回限りしか使わない
```
data := struct {
	TotalCount     int
	CompletedCount int
	PendingCount   int
	Tasks          []Task
	Created_at     time.Time
	CurrentPage    int
	PrevPage       int
	NextPage       int
}{
	TotalCount:     len(tasks),
	CompletedCount: completedCount,
	PendingCount:   pendingCount,
	Tasks:          tasks,
	Created_at:     created_at_time,
	CurrentPage:    page,
	PrevPage:       page - 1,
	NextPage:       page + 1,
}
```
# ブランク識別子（_）について
- 1は「失敗したかどうか（error）」の1つだけ戻り値として返ってくる
- 2は2つの報告が来るから、1つ目の報告はゴミ箱（_）に捨てて、2つ目の報告を err の箱に入れるという形になる
```
1. err = tmpl.Execute(w, models.Data)
2. _ , err = tmpl.Execute(w, models.Data)
```
